# How to Add the Syncfusion Blazor Split Button to a Blazor Web App

A quick start Blazor project that shows how to create and configure the Syncfusion Blazor Split Button component in a .NET 10 Blazor Web App (Interactive Auto). This project also includes a code snippet to add icons, change icon positions, display Split Button items horizontally and bind the OnOpen event to the Blazor SplitButton component.

**Example**: https://blazor.syncfusion.com/demos/buttons/split-button?theme=bootstrap4

**Documentation**: https://blazor.syncfusion.com/documentation/split-button/getting-started

## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Visual Studio 2022 (17.14 or later) or Visual Studio Code

## Project structure

This sample uses the .NET 10 Blazor Web App layout:

* `GettingStarted` — server host (`Components/App.razor` holds stylesheet and script references; the Syncfusion script is in the `<body>`).
* `GettingStarted.Client` — interactive WebAssembly client (`Pages/Home.razor` hosts the Split Button).
* `GettingStarted.slnx` — solution file.

## How to run the project

* Open `GettingStarted.slnx`.
* Restore the NuGet packages by rebuilding the solution.
* Run the `GettingStarted` project.
